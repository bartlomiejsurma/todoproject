# todoproject
Simple Flask-based task management and travel tracker.

## Project structure
- `app/` – Flask application package
- `app/static/` – static assets, including uploaded images and gallery media
- `app/templates/` – Jinja2 templates used by the application
- `app/tests/` – unit tests for database and chart utilities
- `run.py` – application entrypoint for local development
- `requirements.txt` – Python dependencies

## Usage
1. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Run the app locally:
   ```bash
   python run.py
   ```
